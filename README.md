# ⚖ 合乎周礼 (zhouli)

> 以《周礼》六官之道，审视每一次代码操作。

一个 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 插件，将中国古代《周礼》的治理智慧映射到现代软件工程实践。每次代码变更后，自动给出**文言风格的判词**——合礼、失礼、或大逆不道。

## 六官之道

《周礼》以六官分掌天下之事，本插件将其映射为软件工程的六个审视维度：

| 周礼六官 | 工程之道 | 审视范围 |
|----------|---------|---------|
| **天官冢宰** | 治理之道 | 架构设计、职责分离、模块划分 |
| **地官司徒** | 教化之道 | 可读性、命名规范、代码自解释 |
| **春官宗伯** | 礼仪之道 | 编码规范、格式约定、API 契约 |
| **夏官司马** | 征伐之道 | 性能优化、资源效率、算法复杂度 |
| **秋官司寇** | 刑法之道 | 安全防护、错误处理、边界校验 |
| **冬官考工记** | 营造之道 | 工程实践、工具链、构建流程 |

## 安装

### 方式一：使用 Claude Code CLI（推荐）

```bash
claude plugins install --dir /path/to/zhouli
```

### 方式二：手动安装

1. 克隆仓库：

```bash
git clone https://github.com/yuezengwu/zhouli.git
```

2. 在 `~/.claude/settings.json` 中启用插件：

```json
{
  "enabledPlugins": {
    "zhouli@local": true
  }
}
```

3. 在 `~/.claude/plugins/installed_plugins.json` 中注册：

```json
{
  "plugins": {
    "zhouli@local": [
      {
        "scope": "user",
        "installPath": "/path/to/zhouli",
        "version": "1.0.0"
      }
    ]
  }
}
```

4. 重启 Claude Code 会话即可生效。

## 判定标准

| 判定 | 含义 |
|------|------|
| **合礼** ✅ | 操作遵循最佳实践，代码清晰规范，架构合理 |
| **失礼** ⚠️ | 有不当之处但不严重——命名欠佳、轻微冗余、缺少注释 |
| **大逆不道** ❌ | 严重违反工程实践——安全漏洞、架构破坏、数据丢失风险 |

## 特色

- **自动判定**：无需手动调用，每次实质性操作后自动给出判词
- **文言风格**：判词融合文言与白话，庄重而不失趣味
- **六维审视**：从架构到安全，覆盖软件工程核心关注点
- **先行谏言**：对不合理的请求，在执行前直言进谏
- **极简实现**：单个 SessionStart hook，零依赖，即装即用

## 与同类项目的差异

| | 合乎周礼 | oh-my-claude |
|---|---------|-------------|
| 定位 | 操作判定系统 | 多 Agent 编排框架 |
| 触发方式 | 自动（每次操作） | 手动（/review） |
| 文化主题 | 《周礼》六官体系 | 泛传统文化人物 |
| 输出风格 | 文言判词 | 标准 review |
| 复杂度 | 单 hook，零依赖 | 20+ Agent，33+ Hook |
